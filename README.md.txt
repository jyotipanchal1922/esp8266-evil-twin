# ESP8266 Evil Twin Demo

Educational cybersecurity awareness project using ESP8266.

## Overview
This project demonstrates how a Rogue Access Point (Evil Twin) can imitate a Wi-Fi network and redirect users to a captive portal for cybersecurity awareness and educational purposes.

## Features
- Fake Wi-Fi Access Point
- Captive Portal Redirection : A fake login page where users unknowingly enter their WiFi credentials.
- ESP8266-based Setup
- Wireless Security Demonstration

## Technologies Used
- ESP8266
- Arduino IDE
- HTML/CSS 
- Wi-Fi Networking

## Learning Outcomes
- Basics of wireless security
- Rogue AP concepts
- Captive portal working
- Social engineering awareness

## Disclaimer
This project is created strictly for educational and ethical cybersecurity learning purposes in controlled environments only.
